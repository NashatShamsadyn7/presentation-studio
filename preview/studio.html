Why “Running”?

The key text runs alongside the message during encryption. Each letter is encrypted with a different key letter, and the key never repeats.

Encryption vs. Decryption

Encryption

Convert both texts to numbers, add them, then take the result modulo 26.

Cᵢ = ( Pᵢ + Kᵢ ) mod 26

Decryption

Subtract the key numbers from the ciphertext numbers, again modulo 26.

Pᵢ = ( Cᵢ − Kᵢ ) mod 26

Introduction

A classical cipher that trades key length for security.

The Running Key Cipher is a form of classical encryption that uses a long passage of ordinary text — a sentence, a paragraph, or an entire book — as its key. Every letter of the message is shifted according to the matching letter of that key text. Because the key is as long as the message and never repeats, the frequency patterns that break simpler ciphers largely disappear, which made it far stronger than the repeating-key methods that came before it.

How It Works
AI IMAGE
  • Align the key text with the message, letter by letter.
  • Convert both into numbers using A = 0 … Z = 25.
  • Add the pairs together and take the result modulo 26.

Strengths & Weaknesses

✓Strengths

  • No repeating key to detect
  • Very large effective key space
  • Simple to teach and to compute by hand

✕Weaknesses

  • Key text carries natural-language structure
  • Key must match the message in length
  • Vulnerable to crib-dragging attacks
