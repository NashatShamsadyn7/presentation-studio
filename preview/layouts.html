Why “Running”?

The key text runs alongside the message during encryption. Each letter is encrypted with a different key letter, and the key never repeats.

Encryption vs. Decryption

Encryption

Convert both texts to numbers, add them, then take the result modulo 26.

Cᵢ = ( Pᵢ + Kᵢ ) mod 26

Decryption

Subtract the key numbers from the ciphertext numbers, again modulo 26.

Pᵢ = ( Cᵢ − Kᵢ ) mod 26
